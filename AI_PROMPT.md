# AI Prompt: Hookah Store Luxury E-Commerce Website

Create a premium e-commerce website for a hookah delivery brand called Hookah Store. The site should feel dark, luxurious, and atmospheric, inspired by a high-end lounge aesthetic.

## Requirements
- Use plain HTML, CSS, and JavaScript only for the frontend.
- Build a responsive single-page storefront with:
  - a full-bleed hero section,
  - a premium product grid,
  - a sticky/cart-style checkout panel,
  - a responsive order form,
  - WhatsApp and M-Pesa-friendly call-to-action flow.
- Use the following brand palette:
  - Deep obsidian: #0D0D0D
  - Amber gold: #C8962A
  - Smoke white: #F0EDE8
  - Ember red: #8B1A1A
  - Muted charcoal: #1E1E1E
- Use the following type pairing:
  - Cinzel for headings/logo
  - Inter for body text/UI
- Add subtle motion details:
  - smoke-trail hero animation,
  - floating ember particle effects,
  - polished hover states.
- Use imagery from the provided local assets or referenced product images. If Instagram is restricted, use the provided local image set and create a luxury visual feel around them.
- Build a simple Node.js backend with Express and a start script using npm start.
- Expose these endpoints:
  - GET /api/products
  - POST /api/orders
  - GET /health
- The frontend should fetch products from the backend and allow users to add items to a cart and submit a checkout request.

## Deliverables
1. A polished landing page for Hookah Store.
2. A working Node.js server that serves the frontend and API.
3. A modern, mobile-friendly UI with strong visual branding.
4. A clean, maintainable code structure.

## Tone and style
- Luxury, moody, premium, elegant.
- Modern and cinematic, like a private hookah lounge turned digital storefront.
